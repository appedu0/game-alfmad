# لعبة صائد مدّ الألف 🎯

لعبة تعليمية تفاعلية للأطفال لتدريبهم على تمييز الكلمات التي تحتوي على **مدّ بالألف**.

## المعلمة
**اسراء سعد ناصر عبد الغني**

## محتويات المشروع
- `index.html` — الواجهة الأساسية.
- `style.css` — التصميم والحركات والمؤثرات.
- `game.js` — منطق اللعبة، الكلمات، النقاط، المستويات، الأصوات.
- `README.md` — هذا الملف.

## طريقة التشغيل
افتح ملف `index.html` مباشرة في المتصفح.

## الرفع على GitHub Pages
1. أنشئ Repository جديدًا.
2. ارفع الملفات الأربعة في جذر المستودع.
3. من **Settings → Pages**.
4. اختر **Deploy from a branch**.
5. اختر فرع `main` والمجلد `/root`.
6. احفظ الإعدادات.

## مميزات اللعبة
- واجهة عربية RTL.
- إدخال اسم الطالب.
- اسم المعلمة ظاهر في شاشة البداية وأثناء اللعب.
- تصويب بالماوس واللمس.
- كلمات تطير في السماء.
- 3 مستويات متدرجة.
- نقاط + Combo + محاولات.
- تغذية راجعة فورية.
- مؤثرات صوتية بدون ملفات صوت خارجية.
- متجاوبة مع اللابتوب والجوال.
- لا تعتمد على مكتبات JavaScript خارجية.

## تعديل الكلمات
افتح `game.js` ثم عدّل:
- `wordBank.correct` للكلمات التي تحتوي على مدّ بالألف.
- `wordBank.wrong` للكلمات التي لا تحتوي على مدّ بالألف.

> يفضّل كتابة الكلمات بالتشكيل للأطفال الصغار حتى يكون الهدف الصوتي واضحًا.
